# Activity archetypes — weekly patterns by domain

Use these to generate variety across a placement. Pair with field-profiles.md (which gives
the task taxonomy) to produce logbook entries that feel like a real arc, not a repeated list.

Each archetype shows a Monday-to-Friday pattern for one type of week. Rotate these across the
placement so the same type of week never appears more than twice in a row.

---

## ARCHETYPE 1 — Setup and orientation week (use for weeks 1–2)

| Day | Focus | Entry shape |
|---|---|---|
| Mon | Company induction, safety walk-through | Attended induction, toured departments, received PPE/access card, noted emergency exit routes |
| Tue | Shadow a senior technician; observe the primary tool or system | Observed [tool] in use; documented the steps the technician followed; asked questions about error conditions |
| Wed | Asset or environment inventory | Catalogued [devices/servers/cables] in the [department], recorded serial number ranges, updated the asset sheet |
| Thu | First supervised task (simple, low-risk) | Performed [task] under direct supervision; technician reviewed the result before sign-off |
| Fri | Written reflection; update logbook notes | Reviewed the week's observations, organised handwritten notes into the logbook, identified concepts to research |

---

## ARCHETYPE 2 — Fault diagnosis and repair week

| Day | Focus | Entry shape |
|---|---|---|
| Mon | Receive and triage fault tickets | Logged incoming fault reports, categorised by urgency (hardware/software/connectivity), assigned to the correct queue |
| Tue | On-site fault investigation | Travelled to [location], reproduced the fault, ruled out the most common causes in order before isolating the root cause |
| Wed | Repair or reconfiguration | Applied the fix (cable replacement / config change / component replacement), documented each step |
| Thu | Verification and user sign-off | Tested the repair under normal operating conditions, confirmed with the end user, updated the ticket as resolved |
| Fri | Preventive check on adjacent systems | Inspected related equipment for signs of the same fault pattern; updated maintenance records |

---

## ARCHETYPE 3 — Software development and testing week

| Day | Focus | Entry shape |
|---|---|---|
| Mon | Sprint planning, issue assignment | Attended sprint standup, read the assigned ticket, studied the relevant section of the codebase |
| Tue | Feature development or bug fix | Wrote the fix/feature in [language], tested locally, committed to a feature branch with a descriptive message |
| Wed | Unit tests and code review | Wrote unit tests for the new code, ran the test suite, addressed feedback from a code review comment |
| Thu | Integration and staging test | Deployed the branch to the staging server, ran integration tests, confirmed the feature behaved as specified |
| Fri | Documentation and PR merge | Updated the README or internal wiki, merged the approved pull request, closed the issue |

---

## ARCHETYPE 4 — Network configuration and documentation week

| Day | Focus | Entry shape |
|---|---|---|
| Mon | Network audit and diagram update | Traced cable runs, updated the topology diagram to reflect recent changes, noted unlabelled ports |
| Tue | Switch or router configuration | Logged into the admin panel, reviewed port assignments and VLAN memberships, made approved changes |
| Wed | Wi-Fi survey or IP record update | Walked the coverage area with a device, recorded signal strength at key locations, updated the DHCP/IP register |
| Thu | Backup link or failover test | Simulated a WAN failure, verified the backup link activated within the expected time, documented the failover test result |
| Fri | User support and ticket closeout | Resolved outstanding helpdesk tickets (password reset, driver update, printer queue clear), documented solutions |

---

## ARCHETYPE 5 — Data, reporting and automation week

| Day | Focus | Entry shape |
|---|---|---|
| Mon | Data collection and review | Pulled the weekly data export, checked for missing records, cleaned obvious errors in a script or spreadsheet |
| Tue | Analysis and visualisation | Computed summary statistics, plotted the data in [tool], noted trends and anomalies for the team |
| Wed | Script or automation development | Wrote a Python/shell script to automate [manual task], tested on a sample, reviewed edge cases |
| Thu | Report writing and presentation | Drafted the weekly technical report for the team, incorporated the charts, walked the supervisor through the findings |
| Fri | Documentation and handover | Wrote up the script's instructions and saved them to the shared folder so the next person could run it independently |

---

## ARCHETYPE 6 — Hardware assembly, testing and maintenance week

| Day | Focus | Entry shape |
|---|---|---|
| Mon | Preventive maintenance round | Inspected [equipment] per the maintenance schedule, cleaned filters and cooling vents, recorded any anomalies |
| Tue | Component replacement | Replaced [component] in [device], tested under load before returning to service, updated the maintenance log |
| Wed | Breadboard or bench prototyping | Assembled a test circuit for [function] on a breadboard, verified operation with a multimeter, documented component values |
| Thu | Functional testing | Ran the full test procedure from the datasheet, recorded results in the test sheet, flagged any out-of-spec readings |
| Fri | Enclosure and wiring tidy-up | Routed and labelled cables inside [panel/device], secured with cable ties, verified no pinching or strain before closing the enclosure |

---

## ARCHETYPE 7 — Project delivery and handover week (use for final 1–2 weeks)

| Day | Focus | Entry shape |
|---|---|---|
| Mon | Final testing and sign-off preparation | Ran the complete acceptance test for the project, documented all pass/fail results, prepared the handover summary |
| Tue | Documentation finalisation | Updated the system documentation, wrote the user guide or runbook, archived all project files |
| Wed | Knowledge transfer to permanent staff | Walked the junior technician or the receiving team through the completed work; answered questions; left written notes |
| Thu | Final supervisor review | Presented the work summary to the supervisor, received feedback, noted recommendations for future interns |
| Fri | Logbook and report wrap-up | Completed outstanding logbook entries, reviewed for consistency, obtained supervisor signature on the final week |

---

## Pacing reminders

- Mix archetype types. Do not run the same archetype for consecutive weeks.
- Escalate the verb across the placement:
  Weeks 1–2: observed, assisted, shadowed, helped.
  Weeks 3–6: performed under supervision, tested, configured, wrote.
  Weeks 7+: carried out independently, led, documented, handed over.
- Keep at least one unglamorous day per week in the final blend (inventory, documentation,
  waiting for parts, a team meeting). Real placements have them.
